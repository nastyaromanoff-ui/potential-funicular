Артикулы ·

Тренд считается к предыдущему закрытому месяцу. Формула прогноза (значение ÷ дней отчёта × дней в месяце) применена ко всем метрикам, включая CTR, конверсии и % выкупа — по твоему запросу. «Из них РК» и «% скидки МП» в текущих выгрузках WB отсутствуют — метрика недоступна, пока не пришлёшь отчёт с этими данными.
Клик по строке раскрывает остатки по кластерам (регионам) WB. Статусы рассчитаны по остатку и среднесуточным заказам: Дефицитный ≤14 дн. запаса, Популярный 15–45 дн., Достаточно 46–90 дн., Избыточный >90 дн., Без продаж — остаток есть, продаж нет, Нет остатка — 0 шт.

Комплектность продаж ·

Отдельная справка вне месячных вкладок. Правило: если в названии явно указано «4 шт» — это комплект на 4 шт, всё остальное считается комплектом на 2 шт. Учитываются только артикулы L.LOCKER (начинаются на 7).

Остатки WB по кластерам

Без учёта региона «Маркетплейс» (центральный склад) — только распределение по реальным региональным кластерам. Статус считается по формуле: дни запаса = остаток ÷ среднесуточные заказы («Общее среднее кол-во заказов» из файла).
